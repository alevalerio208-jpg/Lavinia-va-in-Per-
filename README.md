# Lavi, da Firenze al Perù

Un gioco in pixel art, stile Game Boy, sulla vita di Lavi a Firenze: dalla Grotta Guelfa alla discussione della tesi, fino alla partenza per Lima.

## Giocare
Apri il link della pagina GitHub Pages del repository. Il gioco parte subito nel browser.

## Installarlo sul telefono
- **Android (Chrome):** compare il pulsante INSTALLA in basso, oppure menu ⋮ → "Installa app".
- **iPhone (Safari):** Condividi → "Aggiungi a schermata Home".

Una volta installato si apre a schermo intero, come un'app, e funziona anche senza connessione.

## Pubblicazione
I file sono tutti statici: `index.html`, `manifest.webmanifest`, `sw.js`, le icone. Basta attivare GitHub Pages sul branch principale, cartella root.
